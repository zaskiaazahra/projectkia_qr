# QR Code Generator Project

Project QR Code Generator berbasis *PHP, MySQL, HTML, CSS, Bootstrap, JavaScript, Vue.js, dan React.js*.

 Deskripsi Project

Aplikasi ini memungkinkan pengguna membuat berbagai jenis QR Code untuk berbagai kebutuhan dan dapat di-scan menggunakan kamera smartphone.

QR Code dapat digunakan untuk berbagai kebutuhan seperti:

- Text / Message
- Website URL
- Email
- Phone Number
- WhatsApp Message
- Payment Information

Project ini dibuat dengan tampilan antarmuka (UI) sederhana dan modern menyerupai website QR Code Generator pada umumnya.

---

 Fitur Utama

✅ Generate QR Code otomatis  
✅ QR dapat di-scan menggunakan kamera smartphone  
✅ Download QR Code ke format gambar (.png)  
✅ Mendukung berbagai tipe QR Code:

- Text
- URL
- Email
- Phone Number
- WhatsApp
- Payment

✅ Visit Counter menggunakan MySQL  
✅ Penyimpanan history QR ke database  
✅ Vue.js untuk logic aplikasi  
✅ React.js untuk widget digital clock  
✅ Responsive design menggunakan Bootstrap

 Cara Menjalankan Project

### 1. Clone Repository

```bash
git clone https://github.com/zaskiaazahra/projectkia_qr.git
```

### 2. Simpan Project ke Folder XAMPP

Masukkan project ke folder:

```txt
xampp/htdocs/
```

### 3. Jalankan XAMPP

Buka **XAMPP Control Panel**, lalu aktifkan:

- Apache
- MySQL

### 4. Import Database

Buka browser:

```txt
http://localhost/phpmyadmin
```

Buat database baru:

```txt
qr_generator_db
```

Lalu import file database SQL.

### 5. Jalankan Project

Buka browser dan akses:

```txt
http://localhost/projectkia_qr
```
